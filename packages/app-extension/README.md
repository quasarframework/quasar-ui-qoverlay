The QOverlay App Extension installs and registers the
[`@quasar/quasar-ui-qoverlay`](https://www.npmjs.com/package/@quasar/quasar-ui-qoverlay)
component package in a Quasar CLI Vite project.

## Install

```bash
quasar ext add @quasar/qoverlay
```

## Uninstall

```bash
quasar ext remove @quasar/qoverlay
```

## Requirements

- Quasar v2.
- `@quasar/app-vite` >=3.0.0.

QOverlay v3 does not support webpack-based Quasar apps. If your application is still using
`@quasar/app-webpack`, migrate the app to Quasar CLI Vite before installing this app extension.
